## 打印与张贴 { #printing-and-fitting }

1. 请按 <strong>100 % /“实际大小”</strong>打印，不要选“适合页面”。每个标签为 <strong>63 × 52 mm</strong>，二维码宽 34 mm。
2. 沿灰色线裁剪。将标签贴在使用仪器时站立的位置，与视线齐平，并远离高温表面（马弗炉、烘箱门、旋蒸水浴）。
3. 用透明胶带或塑封膜保护：溶剂和手套会很快磨损纸质标签。
4. <strong>贴好后用手机扫描一次。</strong>如无法打开页面，请重新打印——不要在仪器上留下失效的标签。

<small>标签由仓库中的 `tools/make_qr_labels.py` 生成。如网站地址变更，请更新脚本中的 `SITE` 并重新运行；保存前它会逐一解码检查每个二维码。</small>
