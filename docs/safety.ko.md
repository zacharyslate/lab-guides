# 안전 우선

이 규칙은 모든 장비에 적용됩니다. 각 가이드는 해당 장비에 특유한 위험을 추가로 설명합니다.

## 개인 보호구

- 실험복, 보안경, 발가락을 덮는 신발, 긴 바지 — 항상 착용.
- 화학물질에는 니트릴 장갑. 글러브박스에서는 <strong>박스의 부틸 장갑 위에 니트릴 장갑</strong>을 착용.
- 머플로, 건조기, 뜨거운 분쇄 용기에는 내열 장갑과 안면 보호구.
- 빔이 차폐되지 않은 상태의 라만 분광기에는 레이저 보안경.

## 우리 재료에 특유한 위험

| 위험 | 장소 | 조치 |
|---|---|---|
| 황화물(Li₂S, P₂S₅, Li₃PS₄, Li₆PS₅Cl)이 수분과 만나 생기는 <strong>H₂S</strong> | 글러브박스, 분쇄 용기, 폐기물 | 황화물은 아르곤 하에서만 다룹니다. 사용한 분쇄 용기와 바이알은 글러브박스 안에서 엽니다. 황화물을 공기 중에서 건조기나 머플로에 넣지 않습니다. 황화물 폐기물은 실험실 절차대로만 중화합니다 |
| <strong>금속 리튬</strong> | 글러브박스, 전지 조립 | 물에서 멀리 둡니다. 깨끗하게 자른 조각만 사용합니다. Li 부스러기는 실험실 절차대로 폐기합니다 |
| <strong>가연성 / 유독 용매</strong>(에탄올, 아세토니트릴, THF) | 글러브박스, 회전 증발기 | 소량, 병은 닫아 둡니다. 건조기에는 절대 넣지 않습니다 |
| <strong>진공과 압력</strong> | 전실, 회전 증발기, Monowave 바이알, 유압 프레스 | 유리에 금이 없는지 확인합니다. 닫힌 용매 병에 완전 진공을 걸지 않습니다. 바이알 한계를 지킵니다 |
| <strong>클래스 3B 레이저</strong> | Cora 5001, Monowave 400 R 프로브 | 프로브를 움직이기 전에 비활성화합니다. 프로브나 광섬유를 절대 들여다보지 않습니다 |
| <strong>뜨거운 표면</strong> | 오일 배스(≤ 180 °C), 머플로(실험실 한계 ≤ 1100 °C), 분쇄 용기(≤ 110 °C) | 장갑, 집게, 식을 때까지 대기 |
| <strong>움직이는 부품</strong> | 볼밀, 회전 증발기 승강 장치 | 뚜껑을 닫습니다. 클램프와 승강부에서 손가락을 멀리합니다 |

## 문제가 생기면

- <strong>글러브박스 안에서 엎지르거나 유리가 깨진 경우:</strong> 작업을 멈추고, 문을 닫은 채로 두고, 실험실 책임자에게 알리십시오.
- <strong>글러브박스의 O₂/H₂O가 높은 경우:</strong> 민감한 용기를 모두 닫고 실험실 책임자에게 알리십시오. 직접 재생하지 마십시오.
- <strong>썩은 달걀 냄새(H₂S):</strong> 그 자리를 떠나 주변에 알리고 실험실 책임자를 부르십시오.
- <strong>화재, 부상, 노출:</strong> 실험실에 게시된 연구소 비상 절차를 따르십시오.
