# 安全第一

以下规则适用于所有仪器。每份指南会补充该仪器特有的危险。

## 个人防护装备

- 实验服、护目镜、不露脚趾的鞋和长裤——始终穿戴。
- 处理化学品时戴丁腈手套；在手套箱中，<strong>在手套箱的丁基手套外再戴一层丁腈手套</strong>。
- 使用马弗炉、干燥箱和处理高温球磨罐时，戴耐热手套和面罩。
- 拉曼光谱仪光束未封闭时，戴激光防护眼镜。

## 我们所用材料的特有危险

| 危险 | 场所 | 应对 |
|---|---|---|
| 硫化物（Li₂S、P₂S₅、Li₃PS₄、Li₆PS₅Cl）遇湿产生的 <strong>H₂S</strong> | 手套箱、球磨罐、废物 | 仅在氩气下处理硫化物。在手套箱内打开用过的球磨罐和样品瓶。切勿在空气中将硫化物放入干燥箱或马弗炉。仅按实验室规程中和硫化物废物 |
| <strong>金属锂</strong> | 手套箱、电池组装 | 远离水。只使用干净、切好的锂片。按实验室规程处理锂边角料 |
| <strong>易燃 / 有毒溶剂</strong>（乙醇、乙腈、THF） | 手套箱、旋转蒸发仪 | 小体积、瓶子盖紧。绝不放入干燥箱 |
| <strong>真空与压力</strong> | 过渡舱、旋转蒸发仪、Monowave 反应瓶、液压机 | 检查玻璃器皿有无裂纹；切勿对密封的溶剂瓶抽满真空；遵守反应瓶的限值 |
| <strong>3B 类激光</strong> | Cora 5001、Monowave 400 R 探头 | 移动探头前先禁用激光；切勿直视探头或光纤 |
| <strong>高温表面</strong> | 油浴（≤ 180 °C）、马弗炉（实验室限值 ≤ 1100 °C）、球磨罐（≤ 110 °C） | 戴手套、用镊子/坩埚钳、待其冷却 |
| <strong>运动部件</strong> | 球磨机、旋转蒸发仪升降装置 | 盖子关闭；手指远离夹紧处和升降装置 |

## 出现问题时

- <strong>手套箱内泄漏或玻璃破碎：</strong>停止操作，保持门关闭，并通知实验室负责人。
- <strong>手套箱内 O₂/H₂O 偏高：</strong>关闭所有敏感容器并通知实验室负责人。不要自行再生。
- <strong>闻到臭鸡蛋味（H₂S）：</strong>离开该区域，提醒他人，并呼叫实验室负责人。
- <strong>火灾、受伤或暴露：</strong>按实验室张贴的研究所应急程序处理。
