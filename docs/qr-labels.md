# QR labels for the instruments

Each instrument should carry a QR label so anyone can open its guide and booking page from a phone. If a label is missing, worn or unreadable, download it here, print it and replace it.

## Printing and fitting

1. Print at **100 % / "Actual size"**, not "Fit to page". Each label is **63 × 52 mm**; the QR code is 34 mm wide.
2. Cut along the grey lines. Stick the label where people stand to use the instrument, at eye level and away from hot surfaces (furnace, oven door, rotavapor bath).
3. Protect it with clear tape or a laminating pouch: solvents and gloves wear paper labels quickly.
4. **Scan it with your phone after fitting it.** If it does not open the page, reprint it — do not leave a broken label on the instrument.

<small>The labels are generated by `tools/make_qr_labels.py` in the repository. If the site address ever changes, update `SITE` in that script and run it again; it checks every code by decoding it before saving.</small>
