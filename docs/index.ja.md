## アニメーションの使い方

各ガイドには、装置と、それに使うセルや容器のアニメーションがあります。<strong>▶ 再生</strong> を押して見るか、<strong>◀ / ▶</strong> で 1 ステップずつ進めるか、アニメーションの下にある手順リストの任意のステップをクリックしてください。文章の手順とアニメーションは同じリストなので、どちらに沿って進めても構いません。

## 装置を使う前に

1. [安全規則](safety.md)と装置のガイドを読んでください。
2. 研究室責任者から<strong>実地トレーニング</strong>を受け、装置の試験がある場合は合格してください。
3. 装置を<strong>予約</strong>してください。
4. 実験ノートに、日付、装置、条件、試料、気づいた問題を記録してください。
