# 安全第一

この規則はすべての装置に適用されます。各ガイドでは、その装置に特有の危険を追加で説明します。

## 保護具

- 白衣、保護メガネ、つま先の覆われた靴、長ズボン——常に着用。
- 化学薬品にはニトリル手袋。グローブボックスでは<strong>ボックスのブチル手袋の上にニトリル手袋</strong>を着用。
- マッフル炉、乾燥機、高温の粉砕容器には耐熱手袋とフェイスシールド。
- ビームが遮蔽されていないときのラマン分光器にはレーザー保護メガネ。

## 当研究室の材料に特有の危険

| 危険 | 場所 | 対処 |
|---|---|---|
| 硫化物（Li₂S、P₂S₅、Li₃PS₄、Li₆PS₅Cl）と水分から生じる <strong>H₂S</strong> | グローブボックス、粉砕容器、廃棄物 | 硫化物はアルゴン下でのみ扱う。使用済みの粉砕容器やバイアルはグローブボックス内で開ける。硫化物を大気中で乾燥機やマッフル炉に入れない。硫化物廃棄物は研究室の手順どおりにのみ中和する |
| <strong>金属リチウム</strong> | グローブボックス、電池の組立 | 水から遠ざける。切り出した清浄な小片のみを使う。Li くずは研究室の手順どおりに廃棄する |
| <strong>可燃性 / 有毒溶媒</strong>（エタノール、アセトニトリル、THF） | グローブボックス、ロータリーエバポレーター | 少量、瓶は閉じる。乾燥機には絶対に入れない |
| <strong>真空と圧力</strong> | 前室、ロータリーエバポレーター、Monowave バイアル、油圧プレス | ガラスにひびがないか確認。密閉した溶媒瓶に完全真空をかけない。バイアルの制限値を守る |
| <strong>クラス 3B レーザー</strong> | Cora 5001、Monowave 400 R のプローブ | プローブを動かす前に無効化。プローブやファイバーを絶対にのぞかない |
| <strong>高温の表面</strong> | オイルバス（≤ 180 °C）、マッフル炉（研究室の上限 ≤ 1100 °C）、粉砕容器（≤ 110 °C） | 手袋、トング、冷めるまで待つ |
| <strong>可動部</strong> | ボールミル、ロータリーエバポレーターの昇降装置 | ふたを閉める。クランプや昇降部に指を近づけない |

## 問題が起きたら

- <strong>グローブボックス内でこぼした、ガラスが割れた：</strong>作業を止め、扉を閉じたままにして研究室責任者に連絡してください。
- <strong>グローブボックスの O₂/H₂O が高い：</strong>敏感な容器をすべて閉じ、研究室責任者に連絡してください。自分で再生しないでください。
- <strong>腐った卵のにおい（H₂S）：</strong>その場を離れ、周囲に知らせ、研究室責任者を呼んでください。
- <strong>火災、けが、ばく露：</strong>研究室に掲示されている研究所の緊急時手順に従ってください。
