## So nutzen Sie die Vorführungen

Jede Anleitung enthält eine Animation des Geräts und der Zelle bzw. des Gefäßes, das es verwendet. Drücken Sie **▶ Abspielen**, um sie anzusehen, gehen Sie mit **◀ / ▶** Schritt für Schritt vor oder klicken Sie auf einen beliebigen Schritt in der Liste unter der Animation. Die schriftlichen Schritte und die Animation sind dieselbe Liste — Sie können also beidem folgen.

## Bevor Sie ein Gerät benutzen

1. Lesen Sie die [Sicherheitsregeln](safety.md) und die Anleitung des Geräts.
2. Erhalten Sie eine **praktische Einweisung** durch die Laborleitung und bestehen Sie ggf. die Geräteprüfung.
3. **Buchen** Sie das Gerät.
4. Notieren Sie in Ihrem Laborbuch: Datum, Gerät, Parameter, Probe und alle Auffälligkeiten.
