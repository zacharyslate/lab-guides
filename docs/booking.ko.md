# 장비 예약

장비(전위가변기와 충방전기는 채널도)를 고르고 한 주를 확인한 뒤 양식을 작성하십시오. 캘린더의 빈 시간을 클릭하면 시작 시간이 미리 채워집니다. 예약은 여러 날에 걸칠 수 있습니다(볼밀, 로, 충방전기).

<div id="booking-app" class="bk"></div>

## 예약 방법

1. <strong>기관 이메일</strong>로 양식을 작성합니다. 예약은 바로 저장되고 캘린더에 표시됩니다.
2. <strong>취소</strong>하려면 예약할 때 쓴 같은 브라우저에서 양식 아래의 <em>이 기기에서 한 예약</em> 목록을 사용하십시오. 다른 기기에서는 실험실 관리자에게 요청하십시오.
3. 쓰지 않을 예약은 취소해 주십시오.

## 규칙

- <strong>교육을 받은</strong> 장비만 예약하십시오.
- 제시간에 오십시오. 30분 안에 시작하지 않은 예약은 다른 사람이 쓸 수 있습니다.
- 장시간 실행(충방전기, 볼밀, 로)은 휴지와 냉각을 포함한 <strong>전체 기간</strong>을 예약해야 합니다.
- 고장은 즉시 실험실 책임자에게 알리고 장비 일지에 기록하십시오.

!!! info "개인정보"
    캘린더에는 <strong>이니셜과 그룹</strong>만 표시됩니다. 이름 전체, 이메일, 목적은 실험실 책임자만 볼 수 있습니다.
