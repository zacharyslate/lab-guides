# Büchi Rotavapor R-210

<div class="facts" markdown>

| | |
|---|---|
| <strong>用途</strong> | 減圧下で溶媒を除去する。例：正極コンポジットのスラリー（エタノール + アセトニトリル）の乾燥 |
| <strong>構成</strong> | <strong>Büchi 循環冷却器 F-105</strong>（冷却管の冷媒）· <strong>シリコーンオイル</strong>入りの <strong>Nahita デジタルオイルバス</strong> · 電源スイッチ、<strong>ROTATION</strong> ノブ（0–10）、傾斜ノブ、Combi Clip、電動リフト付きの <strong>R-210</strong> · 縦型冷却管と受けフラスコ · <strong>真空ポンプ V-700</strong> の上の <strong>Büchi 真空コントローラー V-850</strong> |
| <strong>フラスコ</strong> | 大気に敏感な作業用：<strong>バルブアダプター（ガラスコック）</strong>と <strong>Keck クリップ</strong>で閉じた丸底フラスコ。グローブボックス内で組み立てて閉じる（パート 1） |
| <strong>トレーニング</strong> | 必須。予約前にロータリーエバポレーターの試験に合格すること |
| <strong>取扱説明書</strong> | [取扱説明書と参考資料](../manuals.md#rotavapor) |

</div>

!!! danger "安全"
    - 白衣、保護メガネ、手袋、つま先の覆われた靴。
    - シリコーンオイルバスは <strong>180 °C</strong> に達することがあります。バスに水やその他の薬品を絶対に入れないでください。熱い油に水が入ると激しく飛び散ります（Büchi 取扱説明書、§2）。
    - シリコーンオイルは加熱すると大きく膨張します。冷えた状態で半分程度に見えるバスは少なく<strong>ありません</strong>——継ぎ足さないでください。
    - 使用前にすべてのガラス器具にひびや星形の傷がないか確認してください。損傷したガラスは真空下で<strong>内破</strong>するおそれがあります。すべてのすり合わせにクリップを使ってください。

## パート 1——グローブボックス内でフラスコを組み立てる { #part-1-assemble-the-flask-in-the-glovebox }

試料は一度も大気に触れません。フラスコは<strong>グローブボックス内</strong>で充填し、バルブアダプターで閉じてクリップで固定し、ロータリーエバポレーター上で真空下になってから初めて開けます。

<div class="demo" data-demo="rv-glassware">
--8<-- "rv-glassware.svg"
</div>

<div class="demo-steps" markdown>

1. <strong>グローブボックス内に部品をそろえます：</strong>スラリー入りの丸底フラスコ（コルクリング上）、ガラスコック付きの<strong>バルブアダプター</strong>、<strong>真空グリース</strong>、すり合わせに合った <strong>Keck クリップ</strong>。
2. <strong>ガラスを確認します。</strong>すり合わせは清浄で欠けがないこと。フラスコにひびや星形の傷がないこと——真空がかかります。
3. <strong>すり合わせにグリースを塗ります。</strong>アダプターの下側（オス）すり合わせの上部にだけ、真空グリースを<strong>細い帯状</strong>に塗ります。塗りすぎるとフラスコ内に流れ込み試料を汚染します。
4. <strong>差し込んで回します。</strong>アダプターをフラスコの首に差し込み、グリースの帯が筋や空気の通り道なく透明で連続するまで静かに回します。
5. <strong>すり合わせを固定します。</strong>アダプターが抜けないよう、すり合わせに <strong>Keck クリップ</strong>を取り付けます。
6. <strong>バルブを閉じます。</strong>コックを<strong>水平 = 閉</strong>にします（垂直 = 開）。
7. <strong>最終確認：</strong>クリップ装着、バルブ水平、フラスコにラベル。上側のすり合わせ（ロータリーエバポレーターに付ける側）は清浄に保ちます。
8. 前室から<strong>取り出し</strong>（[グローブボックスのガイド](glovebox.md#taking-material-out)）、フラスコの胴を持ってロータリーエバポレーターまで運びます。パート 2 のステップ 9 まで<strong>バルブは閉じたまま</strong>にします。

</div>

## パート 2——ロータリーエバポレーターで { #part-2-on-the-rotavapor }

<div class="demo" data-demo="rotavapor">
--8<-- "rotavapor.svg"
</div>

<div class="demo-steps" markdown>

1. <strong>安全確認。</strong>保護具を着用し、オイルの量とガラス器具を確認します。バスにはシリコーンオイルだけが入っていること。
2. <strong>チラーの電源だけを入れます。</strong>F-105 の緑の電源スイッチを押すと、表示部に SET TEMP と ACTUAL TEMP が点灯します。START はまだ<strong>押しません</strong>。
3. <strong>オイルバスを設定します。</strong>Nahita バスの電源を入れます（POWER）。<strong>SET</strong> を押し、◄ ▼ ▲ で設定値（<strong>SV</strong>、緑）を変え、もう一度 <strong>SET</strong> を押します。<strong>PV</strong>（赤）は実際の油温です。
4. V-850 真空コントローラー（Manual モード）で<strong>圧力を設定します</strong>。<strong>Set</strong> ソフトキーを押し、黒いノブを手順で指定された圧力まで回して確定します。設定値は表示の上部（「Set … mbar」）に、大きな数字は実際の圧力です。
5. <strong>受器フラスコを取り付けます。</strong>すり合わせに真空グリースを薄く塗り、球面すり合わせクリップでコンデンサーの下に固定します。
6. <strong>パート 1 のフラスコを取り付けます。</strong>コックがまだ<strong>水平（閉）</strong>であることを確認します。駆動部のロックボタンを押し、アダプターの上側すり合わせを蒸気導管に差し込み（ほとんど力は要りません）、<strong>Combi Clip</strong> で固定します：カラーを押し下げて<strong>時計回り</strong>に回します。固定されるまで片手でフラスコを支えます。
7. <strong>真空を開始します。</strong>真空ポンプ V-700 の電源が入っていること（前面のスイッチ）と設定圧力を確認し、コントローラーの <strong>START</strong> を押します。閉じたフラスコはまだ真空にさらされません。
8. 真空を約 5 分かけた後、<strong>チラーの冷却を開始します</strong>。F-105 の <strong>START</strong> を押すと表示に雪の結晶が現れ、ACTUAL TEMP が SET TEMP に向かって下がります。
9. <strong>フラスコを開けて回転を始めます。</strong>チラーが 5 分以上冷却したら、コックを<strong>ゆっくり</strong>開く方向に回します（ハンドルをアダプターと同じ向きに）。圧力が一時的に上がります。ロータリーエバポレーターの電源を入れ（上部パネルの緑のスイッチ）、<strong>ROTATION</strong> ノブを必要な速度まで回します。
10. <strong>位置を調整します。</strong>駆動部の黒いノブでフラスコの傾きを調整し、電気スイッチ付きのハンドルでガラス部全体を上下させます。リフト下部の安全ストッパーがフラスコの下がりすぎを防ぎます。
11. <strong>フラスコをゆっくり</strong>オイルバスに<strong>下げます</strong>。
12. <strong>蒸発させます。</strong>溶媒はコンデンサーで凝縮し、受器フラスコにたまります。突沸に注意し、起きたらフラスコをバスから上げて設定圧力を上げます。
13. <strong>空気を入れずに終了します。</strong>真空をかけたまま、コックを開けたまま回転を止め（<strong>ROTATION</strong> ノブを 0 に）、フラスコをバスから上げて真空下で冷まします。そのあとで初めて<strong>コックを閉じます</strong>（ハンドルがアダプターに対して直角）。
14. <strong>停止してベントします。</strong><strong>STOP を 1 回</strong>押して真空を止め、<strong>2 回</strong>押してベントします。チラーの <strong>STOP</strong> を押し、オイルバスの電源を切ります。フラスコを支え、<strong>Combi Clip を反時計回り</strong>に回して外します。閉じたフラスコ（アダプターと Keck クリップ付き）は開ける前にグローブボックスに戻します。受器フラスコの中身は適切な溶媒廃液容器に捨てます。

</div>

!!! warning "大気に敏感な試料"
    ベント（STOP を 2 回押す）するとガラス部に<strong>空気</strong>が入ります。ベントの<strong>前に</strong>フラスコのコックを<strong>閉じて</strong>いる場合にのみ、試料は保護されます。コックを開けたままベントしないでください。

!!! tip "チラーが冷えるのを待つ"
    5 分は最低限です。フラスコを開くときにチラーの ACTUAL TEMP がまだ SET TEMP よりかなり高いと、溶媒は凝縮せずポンプへ流れます。
