# Fritsch Pulverisette 7 classic line(유성형 마이크로 밀)

<div class="facts" markdown>

| | |
|---|---|
| <strong>용도</strong> | 기계화학 합성과 혼합. 예: 75Li₂S–25P₂S₅ 유리([절차](../procedures/lps-ball-milling.md)) |
| <strong>회전 속도</strong> | 100–800 rpm, 10 단위 |
| <strong>프로그램</strong> | 분쇄 시간, 휴지 시간(각 0–99분 59초, 또는 설정 모드에서 시:분), 반복 0–99, 선택적 역회전 모드 |
| <strong>공기 차단 분쇄</strong> | 실험실에서는 폴리머 개스킷이 있는 ZrO₂ 용기를 PTFE 스페이서와 고무 개스킷과 함께 <strong>스테인리스 탱크 안에</strong> 밀봉 — 글러브박스에서 장입 |
| <strong>교육</strong> | 필수. 고장이나 손상은 즉시 책임자에게 보고 |
| <strong>설명서</strong> | [설명서와 참고 자료](../manuals.md#ball-mill) |

</div>

!!! danger "안전"
    - <strong>밀의 균형을 맞추십시오.</strong> 반대쪽 스테이션에는 항상 <strong>같은 질량</strong>(뚜껑과 개스킷 포함)의 용기를 클램핑하십시오. 빈 카운터 용기는 차이가 70–100 g 미만일 때만 허용됩니다. 불균형 하중은 밀이 작업대 위를 움직이게 합니다.
    - 스핀들 클램프에는 <strong>끼임 위험</strong>이 있습니다. 조일 때 손가락을 멀리하십시오.
    - <strong>화상 위험.</strong> 장시간 실행에서는 용기가 매우 뜨거워집니다(내부가 외벽보다 20–30 °C 높음). 꺼낼 때 내열 장갑을 쓰십시오. 외벽 최고 온도: 100–110 °C(마노: 70–80 °C).
    - 황화물이 든 밀봉 용기를 글러브박스 밖에서 절대 열지 마십시오.

## 시연 { #demonstration }

<div class="demo" data-demo="ball-mill">
--8<-- "ball-mill.svg"
</div>

<div class="demo-steps" markdown>

1. <strong>글러브박스 안에서 용기에 장입합니다.</strong> 분말과 볼을 ZrO₂ 용기에 넣습니다(75Li₂S–25P₂S₅의 경우: 손으로 섞은 분말 1 g과 Ø 5 mm 볼 90 g).
2. 흰색 폴리머 개스킷과 ZrO₂ 뚜껑으로 <strong>용기를 닫습니다</strong>.
3. <strong>강철 탱크를 밀봉합니다.</strong> 용기 아래와 위에 PTFE 스페이서를 하나씩 두고 스테인리스 탱크에 넣은 뒤, 고무 개스킷을 끼우고 탱크를 닫습니다. 그 후에만 글러브박스 밖으로 꺼낼 수 있습니다.
4. 뒷면 주 스위치로 <strong>밀의 전원을 켭니다</strong>(POWER SUPPLY 램프 점등). 뚜껑은 전원이 켜져 있을 때만 열립니다: 손잡이를 누르고 조심스럽게 들어 올립니다.
5. <strong>두 스테이션에 장착합니다.</strong> 코르크 디스크가 있고 눌리지 않았는지 확인합니다. 한 스테이션에 탱크를, 반대쪽에 <strong>같은 질량</strong>의 용기를 놓습니다.
6. <strong>클램핑합니다.</strong> 스핀들 나사(13)를 돌려 압착판이 뚜껑에 평평하게 닿을 때까지 내리고 <strong>손으로</strong> 조입니다. 이어서 잠금 너트(14)를 홀더까지 내리고 손으로 조입니다. 두 스테이션 모두 합니다.
7. + / − 키로 <strong>회전 속도를 설정합니다</strong>(75Li₂S–25P₂S₅ 절차는 510 rpm).
8. <strong>프로그램을 설정합니다.</strong> <strong>MILLING</strong>을 눌러 분쇄 시간을, <strong>PAUSE</strong>를 눌러 휴지 시간(없으면 0)을 설정하고, <strong>REPETITIONS</strong> 횟수를 설정합니다. 구간마다 방향을 바꾸려면 <strong>REVERSE</strong>를 씁니다(최소 1회 반복 필요).
9. <strong>뚜껑을 닫고 START를 누릅니다.</strong> 뚜껑이 잠기고 밀이 돌아갑니다. 과부하면 REDUCED SPEED 램프가 깜빡이고 속도가 낮아집니다.
10. <strong>클램프를 다시 확인합니다.</strong> 처음 몇 분 뒤 <strong>STOP</strong>을 누르고 뚜껑 잠금이 풀리길 기다린 뒤, 두 스핀들 나사와 잠금 너트가 여전히 조여 있는지 확인합니다. <strong>START</strong>를 눌러 계속합니다 — 밀은 경과 시간과 반복 횟수를 기억합니다.
11. <strong>마칩니다.</strong> <strong>STOP</strong>을 누릅니다. 밀이 멈추고 잠시 후 뚜껑 잠금이 풀립니다. 내열 장갑으로 탱크를 꺼내, 열기 전에 글러브박스로 가져갑니다. 주 스위치로 밀의 전원을 끕니다.

</div>

!!! warning "듀티 사이클"
    Pulverisette 7 classic line은 <strong>듀티 사이클 30%의 8시간 교대 근무</strong>(예: 분쇄 3분 + 휴지 7분)용으로 설계되었고 <strong>연속 운전용이 아닙니다</strong>(Fritsch 사용 설명서, §2). 중단 없는 단일 장시간 실행 — 현재 LPS 절차처럼 <strong>휴지 없이 510 rpm에서 24시간</strong> — 은 이 한계를 넘어 마모와 발열을 늘립니다. 24시간을 유지한다면 분쇄/휴지 사이클을 프로그래밍하고 합성에 미치는 영향을 지도교수와 논의하십시오. 휴지는 분말의 열 이력을 바꾸므로 결과를 다시 검증해야 합니다.

## 세척

- 분쇄 부품: 재질별(ZrO₂, 마노, 강철)로 Fritsch <em>Usage, care and cleaning</em> 안내서를 따르십시오. 뜨거운 용기를 찬물에 넣지 마십시오.
- 사용 후 분쇄실을 청소하고, 용기에서 새어 나온 분말이 있으면 보고하십시오(클램프가 풀렸거나 개스킷이 마모된 징후).
