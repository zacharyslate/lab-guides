# Fritsch Pulverisette 7 classic line（行星式微型球磨机）

<div class="facts" markdown>

| | |
|---|---|
| <strong>用途</strong> | 机械化学合成与混合，例如 75Li₂S–25P₂S₅ 玻璃（[流程](../procedures/lps-ball-milling.md)） |
| <strong>转速</strong> | 100–800 rpm，步进 10 |
| <strong>程序</strong> | 研磨时间、暂停时间（各 0–99 分 59 秒，或设置模式下的 时:分）、重复次数 0–99、可选换向模式 |
| <strong>无空气研磨</strong> | 实验室中，带聚合物密封圈的 ZrO₂ 球磨罐与 PTFE 垫片和橡胶密封圈一起密封在<strong>不锈钢罐内</strong>——在手套箱中装料 |
| <strong>培训</strong> | 必需。任何故障或损坏须立即报告负责人 |
| <strong>说明书</strong> | [说明书与参考资料](../manuals.md#ball-mill) |

</div>

!!! danger "安全"
    - <strong>配平球磨机。</strong>在对面的工位上务必夹紧一个<strong>质量相同</strong>的罐（含盖和密封圈）。只有当质量差小于 70–100 g 时，才可使用空的配重罐。负载不平衡会使球磨机在台面上移动。
    - 丝杆夹紧处有<strong>挤压危险</strong>。拧紧时手指远离。
    - <strong>烫伤危险。</strong>长时间运行后球磨罐会非常热（内部比外壁高 20–30 °C）。取出时戴耐热手套。外壁最高温度：100–110 °C（玛瑙：70–80 °C）。
    - 切勿在手套箱外打开装有硫化物的密封罐。

<div class="demo-steps" markdown>

1. <strong>在手套箱中装罐。</strong>将粉末和磨球放入 ZrO₂ 球磨罐（对于 75Li₂S–25P₂S₅：1 g 手工混合的粉末配 90 g Ø 5 mm 磨球）。
2. 用白色聚合物密封圈和 ZrO₂ 盖<strong>封闭球磨罐</strong>。
3. <strong>密封钢罐。</strong>将球磨罐放入不锈钢罐中，上下各垫一片 PTFE 垫片，装上橡胶密封圈并关闭钢罐。此后才能将其移出手套箱。
4. 用后部主开关<strong>打开球磨机</strong>（POWER SUPPLY 指示灯亮）。只有在球磨机通电时盖子才能打开：按下把手并小心抬起。
5. <strong>装载两个工位。</strong>确认软木垫在位且未被压扁。将钢罐放在一个工位，将<strong>质量相同</strong>的罐放在对面工位。
6. <strong>夹紧。</strong>向下旋转丝杆（13）直到压块平贴在盖上，并<strong>用手</strong>拧紧；然后将锁紧螺母（14）旋到支架处并用手拧紧。两个工位都要做。
7. 用 + / − 键<strong>设定转速</strong>（75Li₂S–25P₂S₅ 流程为 510 rpm）。
8. <strong>设定程序。</strong>按 <strong>MILLING</strong> 设定研磨时间，按 <strong>PAUSE</strong> 设定暂停时间（无暂停则为 0），并设定 <strong>REPETITIONS</strong> 次数。若希望每段之后换向，使用 <strong>REVERSE</strong>（至少需要 1 次重复）。
9. <strong>关闭盖子并按 START。</strong>盖子锁定，球磨机开始旋转。若过载，REDUCED SPEED 指示灯闪烁，转速降低。
10. <strong>复查夹紧。</strong>最初几分钟后按 <strong>STOP</strong>，待盖子解锁后，检查两个丝杆和锁紧螺母是否仍然拧紧。按 <strong>START</strong> 继续——球磨机会记住已运行时间和重复次数。
11. <strong>结束。</strong>按 <strong>STOP</strong>；球磨机停止后不久盖子解锁。戴耐热手套取出钢罐，并在打开前将其带入手套箱。用主开关关闭球磨机。

</div>

!!! warning "工作周期"
    Pulverisette 7 classic line 设计用于 <strong>8 小时班次、30% 工作周期</strong>（例如研磨 3 分钟 + 暂停 7 分钟），<strong>不适合连续运行</strong>（Fritsch 操作说明，§2）。一次不间断的长时间运行——如当前 LPS 流程中的<strong>以 510 rpm 无暂停运行 24 小时</strong>——超出这一限制，会加剧磨损和发热。如果要保留 24 小时，请编排研磨/暂停循环，并与导师讨论其对合成的影响：暂停会改变粉末的热历史，因此需要重新验证结果。

## 清洁

- 研磨部件：针对各材料（ZrO₂、玛瑙、钢）遵循 Fritsch <em>Usage, care and cleaning</em> 手册。切勿将热的球磨罐放入冷水中。
- 使用后清洁研磨腔，并报告任何从罐中漏出的粉末（说明夹紧松动或密封圈磨损）。
