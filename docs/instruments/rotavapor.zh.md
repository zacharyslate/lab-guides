# Büchi Rotavapor R-210

<div class="facts" markdown>

| | |
|---|---|
| <strong>用途</strong> | 在减压下除去溶剂，例如干燥正极复合材料悬浮液（乙醇 + 乙腈） |
| <strong>组成</strong> | 冷却器（冷凝器冷却液）、<strong>硅油</strong>加热浴（最高 180 °C）、带倾角旋钮的驱动单元、Combi Clip 和电动升降装置、立式冷凝器、接收瓶、真空控制器和泵 |
| <strong>烧瓶</strong> | 用于空气敏感操作：用<strong>带阀转接头（玻璃旋塞）</strong>和 <strong>Keck 夹</strong>封闭的圆底烧瓶，在手套箱中组装并关闭（第 1 部分） |
| <strong>培训</strong> | 必需。预约前须通过旋转蒸发仪考核 |
| <strong>说明书</strong> | [说明书与参考资料](../manuals.md#rotavapor) |

</div>

!!! danger "安全"
    - 实验服、护目镜、手套和不露脚趾的鞋。
    - 硅油浴可达 <strong>180 °C</strong>。切勿向浴中加入水或任何化学品：热油中的水会引起剧烈飞溅（Büchi 说明书，§2）。
    - 硅油受热会明显膨胀。冷态下看起来半满的油浴<strong>并不</strong>算低——不要补加。
    - 使用前检查所有玻璃器皿有无裂纹或星状裂纹：受损的玻璃在真空下可能<strong>内爆</strong>。所有磨口都要用夹子固定。

## 第 1 部分——在手套箱中组装烧瓶 { #part-1-assemble-the-flask-in-the-glovebox }

样品始终不接触空气：烧瓶在<strong>手套箱内</strong>装料，用带阀转接头封闭并用夹子固定，只在旋转蒸发仪上于真空下重新打开。

<div class="demo" data-demo="rv-glassware">
--8<-- "rv-glassware.svg"
</div>

<div class="demo-steps" markdown>

1. <strong>在手套箱中备齐部件：</strong>装有悬浮液的圆底烧瓶（放在软木圈上）、带玻璃旋塞的<strong>带阀转接头</strong>、<strong>真空脂</strong>，以及与磨口匹配的 <strong>Keck 夹</strong>。
2. <strong>检查玻璃。</strong>磨口应干净、无缺口；烧瓶不得有裂纹或星状裂纹——它将处于真空下。
3. <strong>给磨口涂脂。</strong>只在转接头下部（外）磨口的上端涂一条<strong>细带</strong>真空脂。涂得太多会流入烧瓶并污染样品。
4. <strong>插入并旋转。</strong>将转接头插入烧瓶颈部，轻轻旋转，直到脂带看起来透明连续，无条纹或气道。
5. <strong>固定磨口。</strong>在磨口上装上 <strong>Keck 夹</strong>，使转接头无法滑出。
6. <strong>关闭阀门。</strong>将旋塞转到<strong>水平 = 关闭</strong>（竖直 = 打开）。
7. <strong>最终检查：</strong>夹子已装、阀门水平、烧瓶已贴标签。保持上部磨口（接旋转蒸发仪的一端）清洁。
8. 通过过渡舱<strong>取出</strong>（[手套箱指南](glovebox.md#taking-material-out)），托住烧瓶瓶身将其带到旋转蒸发仪。在第 2 部分第 9 步之前<strong>保持阀门关闭</strong>。

</div>

!!! question "需与实验室幻灯片核对"
    <em>Rotovapor</em> 幻灯片展示了烧瓶阀门（竖直 = 打开，水平 = 关闭）、真空脂、Keck 夹和磨口，并以"关闭 → 去旋转蒸发仪"结尾。只能读取幻灯片中的文字，无法读取照片，因此示意图假定为<strong>圆底烧瓶加独立的旋塞转接头</strong>。如果实验室使用的是一体式带阀烧瓶，则第 3–5 步适用于在手套箱中封闭的那个磨口——请确认。

## 第 2 部分——在旋转蒸发仪上 { #part-2-on-the-rotavapor }

<div class="demo" data-demo="rotavapor">
--8<-- "rotavapor.svg"
</div>

<div class="demo-steps" markdown>

1. <strong>安全检查。</strong>穿戴个人防护装备，检查油位和玻璃器皿。浴中只能是硅油。
2. <strong>打开冷却器——仅接通电源。</strong> <strong>暂不</strong>启动制冷。
3. <strong>设定油浴温度</strong>为您的流程规定的起始温度。
4. 在真空控制器上<strong>设定压力</strong>为您的流程规定的值（取决于溶剂和油浴温度）。
5. <strong>安装接收瓶。</strong>在其磨口上涂一层薄薄的真空脂，并用球形磨口夹将其固定在冷凝器下方。
6. <strong>安装第 1 部分的烧瓶。</strong>确认旋塞仍为<strong>水平（关闭）</strong>。按下驱动单元上的锁定按钮，将转接头的上部磨口套到蒸汽导管上（只需很小的力），并用 <strong>Combi Clip</strong> 固定：将卡圈向下按并<strong>顺时针</strong>旋转。用一只手托住烧瓶直到固定好。
7. <strong>启动真空。</strong>检查设定压力并按真空控制器上的 <strong>START</strong>。此时封闭的烧瓶尚未暴露于真空。
8. 真空运行约 5 分钟后，<strong>启动冷却器制冷</strong>。冷却器显示屏上会出现雪花图标。
9. <strong>打开烧瓶。</strong>冷却器制冷至少 5 分钟后，<strong>缓慢</strong>将旋塞转到打开位置（手柄与转接头同向）——压力会短暂升高——然后开始旋转。
10. <strong>调整位置。</strong>驱动单元上的黑色旋钮调节烧瓶倾角；带电动开关的手柄升降整个玻璃组件。升降装置底部的安全限位可防止烧瓶下降过低。
11. <strong>缓慢将烧瓶降入</strong>油浴。
12. <strong>蒸发。</strong>溶剂在冷凝器上冷凝并收集在接收瓶中。注意暴沸；如发生暴沸，将烧瓶提出油浴并提高设定压力。
13. <strong>在不进空气的情况下结束。</strong>在真空仍开启、旋塞打开的状态下，停止旋转，将烧瓶提出油浴，使其在真空下冷却。之后才<strong>关闭旋塞</strong>（手柄与转接头垂直）。
14. <strong>停止并放气。</strong>按 <strong>STOP 一次</strong>停止真空，按<strong>两次</strong>放气。停止冷却器制冷和油浴加热。托住烧瓶，<strong>逆时针</strong>旋转 <strong>Combi Clip</strong> 将其取下；在打开之前，将封闭的烧瓶（连同转接头和 Keck 夹）带回手套箱。将接收瓶中的液体倒入正确的溶剂废液桶。

</div>

!!! warning "空气敏感样品"
    放气（按两次 STOP）会让<strong>空气</strong>进入玻璃组件。只有在放气<strong>之前关闭</strong>烧瓶旋塞，样品才受到保护。切勿在旋塞打开时放气。

!!! question "待与实验室负责人确认"
    - 启动幻灯片要求在抽真空 5 分钟后开始制冷，再过 5 分钟打开烧瓶。5 分钟可能不足以让冷却液达到温度；未冷凝的溶剂会进入泵中。建议等待冷却器达到设定值。
    - 幻灯片没有给出乙醇/乙腈正极悬浮液的油浴温度或压力。请将经过验证的数值补充到[正极流程](../procedures/cathode-composite.md)中。
