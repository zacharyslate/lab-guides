## グループの論文 { #group-publications }

これらのガイドの方法を用いたグループの論文です。各リンクは出版社のページに移動します。タイトルは発表時の英語のままです。


1. <em>Real-time vibrational fingerprinting of liquid-phase sulfide electrolyte synthesis via in situ Raman spectroscopy.</em> <strong>Inorganic Chemistry Frontiers</strong> 13(4), 1432. [出版社ページ](https://pubs.rsc.org/qi/article/13/4/1432/1248597/Real-time-vibrational-fingerprinting-of-liquid)——[Monowave 400 R](instruments/monowave.md) と [Cora 5001](instruments/cora.md) のガイドに関連。
2. <em>Influence of Halogens on PS₄³⁻ Speciation and Formation Pathways in Acetonitrile.</em> <strong>Inorganic Chemistry</strong> 65(24), 13504. DOI [10.1021/acs.inorgchem.6c01436](https://doi.org/10.1021/acs.inorgchem.6c01436)。
3. <em>Solution-Based Suspension Synthesis of Li₂S–P₂S₅ Glass-Ceramic Systems as Solid-State Electrolytes: A Brief Review of Current Research.</em> <strong>ACS Omega</strong> 9(29), 31228. [出版社ページ](https://pubs.acs.org/acsodf/article/9/29/31228/410242/Solution-Based-Suspension-Synthesis-of-Li2S-P2S5)——[ボールミル](procedures/lps-ball-milling.md)と溶液法の背景。

5. Warren <em>et al.</em> <em>Real-Time, Interpretable Diagnostics for Solid-State Batteries via Machine Learning on In Situ Impedance Spectra.</em> <strong>Battery Energy</strong> (2026). DOI [10.1002/bte2.70122](https://doi.org/10.1002/bte2.70122)——[EIS データ解析](analysis/eis-analysis.md)に関連。
