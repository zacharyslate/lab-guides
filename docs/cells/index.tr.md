## Parçalar nasıl bir araya geliyor

```
Li2S + P2S5 ──(Pulverisette 7)──▶ 75Li2S–25P2S5 camı
LPSC + NMC + VGCF ──(eldivenli kabin → rotavapor)──▶ katot kompoziti
elektrolit tozu ──(kalıp + pres)──▶ pelet ──▶ EIS hücresi ──(PMC-2000)──▶ σ_ion, E_a
elektrolit + katot ──(kalıp + pres)──▶ çift katman ──▶ test bataryası ──(CT-9008)──▶ kapasite, döngüleme
```
