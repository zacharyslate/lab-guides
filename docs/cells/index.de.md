## Wie die Teile zusammenpassen

```
Li2S + P2S5 ──(Pulverisette 7)──▶ 75Li2S–25P2S5-Glas
LPSC + NMC + VGCF ──(Glovebox → Rotavapor)──▶ Kathodenkomposit
Elektrolytpulver ──(Matrize + Presse)──▶ Pressling ──▶ EIS-Zelle ──(PMC-2000)──▶ σ_ion, E_a
Elektrolyt + Kathode ──(Matrize + Presse)──▶ Zweischicht ──▶ Testbatterie ──(CT-9008)──▶ Kapazität, Zyklierung
```
