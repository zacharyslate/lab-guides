## 各要素のつながり

```
Li2S + P2S5 ──(Pulverisette 7)──▶ 75Li2S–25P2S5 ガラス
LPSC + NMC + VGCF ──(グローブボックス → ロータリーエバポレーター)──▶ 正極コンポジット
電解質粉末 ──(金型 + プレス)──▶ ペレット ──▶ EIS セル ──(PMC-2000)──▶ σ_ion, E_a
電解質 + 正極 ──(金型 + プレス)──▶ 二層 ──▶ 試験電池 ──(CT-9008)──▶ 容量、サイクル
```
