## How the pieces fit together

```
Li2S + P2S5 ──(Pulverisette 7)──▶ 75Li2S–25P2S5 glass
LPSC + NMC + VGCF ──(glovebox → Rotavapor)──▶ cathode composite
electrolyte powder ──(die + press)──▶ pellet ──▶ EIS cell ──(PMC-2000)──▶ σ_ion, E_a
electrolyte + cathode ──(die + press)──▶ bilayer ──▶ test battery ──(CT-9008)──▶ capacity, cycling
```
