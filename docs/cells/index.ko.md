## 각 요소의 연결

```
Li2S + P2S5 ──(Pulverisette 7)──▶ 75Li2S–25P2S5 유리
LPSC + NMC + VGCF ──(글러브박스 → 회전 증발기)──▶ 양극 복합체
전해질 분말 ──(다이 + 프레스)──▶ 펠릿 ──▶ EIS 셀 ──(PMC-2000)──▶ σ_ion, E_a
전해질 + 양극 ──(다이 + 프레스)──▶ 이중층 ──▶ 시험 전지 ──(CT-9008)──▶ 용량, 사이클
```
