## Cómo encajan las piezas

```
Li2S + P2S5 ──(Pulverisette 7)──▶ vidrio 75Li2S–25P2S5
LPSC + NMC + VGCF ──(caja de guantes → rotavapor)──▶ composite catódico
polvo de electrolito ──(matriz + prensa)──▶ pastilla ──▶ celda EIS ──(PMC-2000)──▶ σ_ion, E_a
electrolito + cátodo ──(matriz + prensa)──▶ bicapa ──▶ batería de prueba ──(CT-9008)──▶ capacidad, ciclado
```
