## Come si collegano i vari pezzi

```
Li2S + P2S5 ──(Pulverisette 7)──▶ vetro 75Li2S–25P2S5
LPSC + NMC + VGCF ──(glovebox → rotavapor)──▶ composito catodico
polvere di elettrolita ──(stampo + pressa)──▶ pastiglia ──▶ cella EIS ──(PMC-2000)──▶ σ_ion, E_a
elettrolita + catodo ──(stampo + pressa)──▶ doppio strato ──▶ batteria di prova ──(CT-9008)──▶ capacità, ciclazione
```
