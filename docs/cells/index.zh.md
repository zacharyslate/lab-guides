## 各部分如何衔接

```
Li2S + P2S5 ──(Pulverisette 7)──▶ 75Li2S–25P2S5 玻璃
LPSC + NMC + VGCF ──(手套箱 → 旋转蒸发仪)──▶ 正极复合材料
电解质粉末 ──(模具 + 压机)──▶ 片 ──▶ EIS 电池 ──(PMC-2000)──▶ σ_ion, E_a
电解质 + 正极 ──(模具 + 压机)──▶ 双层片 ──▶ 测试电池 ──(CT-9008)──▶ 容量、循环
```
